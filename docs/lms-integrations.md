# LMS-интеграции

Направления интеграции:

- Moodle;
- другие LMS;
- отдельные self-host сайты с тестами;
- встраиваемый frontend-клиент для внешних сайтов.

## Пилот

Пилотный сценарий - подключить TuneAI к реальному учебному курсу и начать с анализа текстовых контрольных ответов. Для проверки качества стоит сравнить AI-оценку с ручной проверкой преподавателя и измерить, помогает ли система быстрее находить слабые темы.

## Требования к API

- создание или синхронизация пользователей;
- создание попыток;
- загрузка аудио- и текстовых ответов;
- получение статуса обработки;
- получение финального результата;
- экспорт оценок и обратной связи.
