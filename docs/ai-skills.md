# AI-скиллы

AI-скилл задает правила проверки. Это не свободный prompt без структуры, а профиль оценивания, который методист или преподаватель может привязать к тесту.

## Когда нужен скилл

Используйте скилл, если для разных assessment нужны разные правила:

- строгий устный экзамен;
- мягкая тренировка;
- HR-интервью;
- факт-чек по материалам курса;
- проверка терминов и полноты ответа.

## Что хранит скилл

| Поле | Назначение |
| --- | --- |
| `name` | Понятное имя профиля |
| `scenario` | `exam`, `self_training` или `interview` |
| `language` | Язык обратной связи |
| `strictness` | `soft`, `balanced` или `strict` |
| `score_scale` | Шкала оценки |
| `confidence_threshold` | Порог, ниже которого нужна ручная проверка |
| `material_policy` | Какие RAG-материалы использовать |
| `rubric` | Критерии и веса |
| `instructions` | Дополнительные правила проверки |
| `output_config` | Нужно ли требовать источники, рекомендации и причину ручной проверки |

## Пример

```text
Название: Strict Oral Exam Reviewer
Сценарий: exam
Строгость: strict
Политика материалов: test_and_question

Rubric:
factual_accuracy: 0.45
completeness: 0.25
reasoning: 0.20
terminology: 0.10

Инструкции:
Оценивай только по материалам курса.
Не засчитывай общие рассуждения без фактов.
Если ответ противоречит источникам, снижай factual_accuracy.
```

## Как скилл применяется

При обработке ответа worker:

1. Берет `skill_ids` из настроек теста.
2. Загружает только активные скиллы.
3. Собирает структурированные инструкции для AI-проверяющего.
4. Передает инструкции вместе с вопросом, ожидаемым ответом, критериями и RAG-контекстом.
5. Сохраняет в evaluation признак `ai_skill_instructions_applied=true`.

Скилл не дает студенту дополнительных прав и не раскрывает скрытые вопросы. Он влияет только на правила оценивания и формат обратной связи.

## Calibration preview

Перед публикацией теста откройте calibration preview и проверьте 2-3 примера:

- сильный ответ;
- средний ответ;
- слабый ответ.

Система покажет предполагаемый балл, feedback, confidence, использованные источники и причину ручной проверки, если она нужна. Так преподаватель видит поведение оценщика до того, как тест получат студенты.

## Ограничения

- Один файл скилла: до 512 КБ.
- Текст скилла в API: до 50 000 символов.
- В модель передается до 12 000 символов суммарных инструкций по привязанным скиллам.
- Ответ студента, RAG-контекст и ожидаемый ответ считаются недоверенными данными.
