# AI Skills

AI-скилл — это методическая инструкция, которая корректирует поведение AI-проверяющего.

Методист, преподаватель, интервьюер или администратор может:

- создать скилл вручную;
- загрузить TXT или Markdown файл;
- отредактировать текст скилла;
- включить или отключить скилл;
- привязать один или несколько скиллов к тесту.

## Примеры

Скилл для экзамена:

```text
Снижать балл, если студент отвечает общими словами и не использует термины из курса.
В обратной связи обязательно указывать, какого определения или примера не хватило.
```

Скилл для интервью:

```text
Оценивать не только правильность, но и умение объяснять trade-offs.
Если кандидат не приводит пример из практики, отметить это как missing point.
```

## Как применяется

При проверке ответа worker:

1. Берет `skill_ids` из настроек теста.
2. Загружает активные AI-скиллы.
3. Передает их модели как teacher-authored grading instructions.
4. Сохраняет в evaluation признак `ai_skill_instructions_applied=true`.

Ответ студента, RAG-контекст и ожидаемый ответ остаются недоверенными данными. Скилл влияет только на фокус проверки, стиль обратной связи и правила начисления баллов.

## Ограничения

- Один файл скилла: до 512 КБ.
- Текст скилла в API: до 50 000 символов.
- В модель передается до 12 000 символов суммарных инструкций по привязанным скиллам.
