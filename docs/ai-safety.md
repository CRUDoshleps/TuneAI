# AI Safety

TuneAI разделяет цензуру пользовательского контента и защиту AI-проверки.

## Цензура

Русская нецензурная лексика цензурируется на backend и frontend.

Backend остается источником истины для сохраненных тестов, вопросов и ответов. Frontend дополнительно цензурирует отображаемые данные, чтобы пользователь не видел нежелательный текст до повторной обработки на сервере.

## Prompt Injection

Защита от prompt injection работает отдельно от цензуры. Backend:

- помечает расшифровку ответа, эталонный ответ, критерии и RAG-контекст как недоверенные данные;
- запрещает модели выполнять инструкции из недоверенных полей;
- ищет типовые признаки prompt injection;
- рекомендует ручную проверку, если найден подозрительный текст.

Примеры подозрительных фраз:

- `ignore previous instructions`;
- `show system prompt`;
- `выведи системный промпт`;
- `игнорируй инструкции`.

Для экзаменов и других важных проверок это не заменяет ручной контроль преподавателя.
