# Roadmap

## Уже реализовано

- self-host запуск через Docker Compose;
- runtime-настройка бренда, цветов, логотипа и публичных текстов;
- роли, отдельный вход администратора и закрытая регистрация новых администраторов;
- создание пользователей, групп и назначение тестов пользователям или группам;
- embedded widget `/widget` для прохождения назначенного теста на внешнем сайте;
- assessment builder с вопросами, критериями, RAG, AI-скиллами и публикацией;
- голосовые, текстовые и смешанные режимы ответа на уровне вопроса;
- скрытие будущих вопросов до ответа на текущий;
- RAG-материалы на уровне организации, курса, теста и вопроса;
- генерация вопросов из RAG-материалов с token budget и кэшем;
- calibration preview для проверки AI-скилла на примерах ответов;
- стабильный API результата попытки;
- idempotency key для безопасной повторной отправки ответов;
- фоновая обработка ответов и индексации через outbox/worker;
- mock AI, Yandex AI Studio, OpenAI-compatible и локальный AI-профиль;
- Moodle service API и smoke-тест;
- CI для backend, frontend, миграций и Docker Compose config.

## Следующие задачи

- улучшить UI редактирования уже созданных вопросов;
- добавить audit log действий администраторов;
- добавить импорт пользователей из CSV;
- добавить экспорт результатов в CSV/PDF;
- добавить повторный запуск упавших задач из админки;
- добавить отдельные отчеты по группам и курсам;
- перенести RAG-поиск на `pgvector` для больших инсталляций;
- подготовить отдельный widget SDK, если iframe станет недостаточно гибким.
