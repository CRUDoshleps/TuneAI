# Roadmap

## Уже заложено в прототипе

- демо-сценарии для самоподготовки, экзамена и интервью;
- проверка голосовых и текстовых ответов;
- RAG-материалы на уровне теста и отдельного вопроса;
- базовая карта компетенций;
- отдельный вход в админку;
- защита от prompt injection;
- стабильный API результата попытки;
- idempotency key для безопасной повторной отправки ответов.

## Ближайшие продуктовые задачи

- интеграция с Moodle;
- интеграции с другими LMS;
- генерация отдельного сайта с тестами;
- встраиваемый клиент для записи и отправки ответов;
- кастомизация frontend прохождения тестов.

## Образовательный контур

- расширенная карта компетенций по студентам и группам;
- более детальные рубрики на уровне вопросов;
- отдельное рабочее место методиста;
- групповая аналитика;
- экспорт отчетов в PDF.

## Платформа

- runtime-конфигурация self-host установок;
- API-токены для интеграций;
- повторный запуск упавших задач обработки;
- audit log для действий администраторов.

## AI

- настраиваемые профили AI-проверяющих;
- перенос RAG-поиска на `pgvector`.
